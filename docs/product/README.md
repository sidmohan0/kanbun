# Product

Product-facing documentation lives here.

Use this directory for user journeys, feature specs, UX notes, and business rules that should be stable enough for contributors and agents to follow.

The architecture baseline lives in the ADRs. This directory translates those decisions into operator-facing behavior.

## Scope of these docs

These documents define:

- who the initial operator is
- what the first user-facing surfaces are
- how core workflows should behave
- which business rules should be treated as implementation constraints

They do not replace the ADRs. Read [ADR-0001](../adr/0001-foundation.md) and the [ADR index](../adr/README.md) alongside these specs.
