# Spec archive

`../../SPEC.md` is the current, locked spec. This folder is its append-only history:

- `SPEC-v<version>.md` — every version in full, as it was when it was current
- `figures/` — diagrams referenced by the markdown

Rules for bumping are in `SPEC.md` under "How this file is versioned"; `scripts/check-spec-lock.mjs` enforces them in CI.
